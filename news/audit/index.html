Audit konten

    Publish ke GitHub

    Token disimpan hanya di sessionStorage dan hilang saat tab ditutup. Fine-grained token butuh Contents: read/write dan Actions: read/write. Tanpa token, gunakan Export lalu commit manual.

    AI Generator

    Menjalankan workflow update-news.yml di GitHub Actions. Artikel baru dibuat oleh model AI, di-commit ke news.json, lalu bisa diaudit di sini.

    Butuh secret NEWS_AI_API_KEY di repositori. Jadwal harian berjalan otomatis; tombol ini memicu run manual dengan topik tertentu.

    Data

    Pratinjau menulis ke localStorage.news_preview lalu membuka /news?preview=1. Tidak ada yang berubah di situs publik.
